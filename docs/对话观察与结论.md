# 对话观察与设计结论

记录日期：2026-10-23；公开整理日期：2026-10-24。观察对象为美人支招 1.7.0 的日常对话功能。测试问题为虚构案例，用户要求中文回答。

## 三个形象的比较

| 样本 | 形象 | 会话安排 | 主要回答特征 |
|---|---|---|---|
| A | 麦克风形象 | 此前已有首轮基线，本轮未重测 | 镜像反馈、减少主动、观察反应 |
| B | 白裙形象 | 另一个账号，新建会话 | 投入下降、责任转移、后撤观察 |
| C1 | 皇冠银黑裙形象 | 新建会话 | 后撤、收回关注，措辞更强 |
| C2 | 与 C1 同一形象 | 再新建会话 | 核心策略近似，但措辞及回复间隔不同 |

四次输入逐字相同。原文见 [同题回答记录](../observations/同题回答记录.md)。A 与其他样本存在账号和时间差异；界面显示新会话，不足以证明后台没有账号画像或跨会话记忆。

本次可见角色配置中，三个形象标识不同，文本角色标识、角色配置和两种语音标识相同。角色名称均为“情感导师”，配置文字为 243 个 Unicode 字符。同一 C 形象两次回答也不相同，因此一次措辞变化不能直接说明形象拥有不同人格。

目前支持“共用一个文本咨询角色”的设计假设；不支持断言模型版本、隐藏规则、采样参数和所有后台路径完全相同。语音标识相同也不等于已完成听感对比。

## 共同的回答组织

四份首轮回答都迅速表态，对比以前与现在的行为，解释“太敏感”怎样转移问题，再提出后撤或减少主动，观察对方是否回应。差异主要在标签、篇幅、语气力度和具体等待天数。

第一形象的后续两轮还表现出两种能力：补充“照顾住院母亲、提前告知、持续联系、主动道歉”后，明确改变原判断；用户要求一句短消息时，仅给话术。见 [连续对话记录](../observations/连续对话记录.md)。这两种能力没有在另外两个形象上重复测试。

总计六份不同输出，其中四份是同题首轮。不能把它们算作六个独立题材，也不足以估计所有场景的稳定性。

## 怎样落实到本项目

| 观察 | v0.3 的设计 |
|---|---|
| 开头迅速给立场 | 首句回答当前核心矛盾 |
| 比较关系投入 | 看相对变化、兑现、主动修复及现实压力 |
| 解释责任转移 | 讲清追问、自证和原问题被搁置的互动循环 |
| 行动导向 | 每轮优先一个主策略，翻译成具体动作 |
| 收尾关注反应 | 观察持续行动，给后续调整条件 |
| 反证出现后改判 | 明确撤回失效建议，不把旧推测当事实 |

原回答中的强烈动机断言和报复性延迟回复没有成为本项目的固定规则。v0.3 保留直接、务实的表达，但把判断落实到可见行为，把后撤落实到停止单方面追逐。这是设计选择，不保证逐字重现原样本。

尚未确认精确模型型号、完整系统消息、知识库、具体采样参数和报告评分算法。当前不据语气猜测模型，也不把本地课程语料当作测试产品的已证实知识源。
