# 角色提示词

三份 system 提示词都是本项目独立编写的版本。通常只选择一份使用，不把多个版本叠加。

| 版本 | 内容 | 使用定位 |
|---|---|---|
| [v0.1](v0.1/system.txt) | 自然、温暖、重视事实与边界 | 初始基线 |
| [v0.2](v0.2/system.txt) | 先判断再行动，明确处理反证与一句话术 | 首轮样本校准 |
| [v0.3](v0.3/system.txt) | 强化投入变化、责任转移、互动循环和条件观察 | 当前默认版本 |

[v0.3 风格示例](v0.3/examples.md) 是人工编写的目标表达，不是自建模型实测结果。若将示例纳入提示词，应明确标注为示范，不把它混进真实用户历史。

另保留 [角色配置参考](../observations/角色配置参考.txt) 作为比较材料。该文本是测试时可见的角色配置字段，不能等同于完整模型系统消息。它与本项目独立设计的 v0.1–v0.3 分开保存。

建议固定模型和参数比较不同版本，第二轮开始使用各组自己的历史回答；不能将样例中的原回答代入历史后，宣称已经验证了自身模型的多轮表现。具体步骤见 [调用与评估](../docs/调用与评估.md)。
